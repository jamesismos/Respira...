# Respira

O Respira nasceu de um propósito pessoal: criar uma ferramenta que pudesse ajudar alguém importante a parar de fumar e viver melhor.

Foi uma forma de transformar cuidado em algo concreto. A solução, porém, não encontrou o valor que eu esperava que tivesse para a pessoa a quem se destinava, e o projeto foi encerrado.

Esta página permanece como registro do trabalho desenvolvido e da intenção que o originou. O projeto não receberá novas funcionalidades nem manutenção contínua.
